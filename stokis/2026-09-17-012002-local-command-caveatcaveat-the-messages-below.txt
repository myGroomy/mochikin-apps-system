  1. Bukan free-form — dropdown terbatas pada 6 tipe: dual, single, boolean,
     date, expiry, text
  2. dual = default — di-enforce di semua layer:
     - UI default item baru → 'dual'
     - Parser fallback (kosong/invalid) → 'dual'
     - Server-side normalizeTipeInput() fallback → 'dual'

     (dual menang jika keduanya ada)
  4. Multi-select — boolean, date, expiry, text bisa dikombinasikan sebagai
     checkbox tambahan (maks 2 combo, plus satu triple khusus:
     dual,boolean,date)

  Jadi dual adalah primary tipe, bukan semuanya bebas.
